## 一、學習目標

| 層次 | 目標描述 |
|------|----------|
| 認知 | 理解絕對值是「點到原點的距離」，不是「去掉負號」的機械操作 |
| 操作 | 能在數線上標示有理數的位置；能計算兩點間的距離 `AB = |a-b|` |
| 推理 | 理解為什麼 `|a| = |-a|`；理解為什麼絕對值不可能是負數 |

---

## 二、核心設計原則

**打破最關鍵迷思：「絕對值只是去掉負號」**

這個迷思的成因是：學生從操作結果（`|-3| = 3`，去掉負號）推導定義，而非從幾何意義（距離）出發。設計的核心是讓**距離的視覺**先於符號的操作。

```
推導路徑：
點到原點的物理距離（直觀感知）
    ↓
負數的距離仍然是正的（Pattern 觀察）
    ↓
|a| 的幾何定義（距離，非去負號）
    ↓
可拖曳的數線驗證
    ↓
雙點距離 |a-b|
    ↓
動態距離變化（青蛙追蟲）
    ↓
迷思挑戰（打破「絕對值可以是負數」的錯誤直覺）
```

## 三、完整分頁架構

### Phase 0｜Pattern 推導（距離的直覺建立）

**教學目標**：讓學生自己「發現」絕對值的定義，而非被告知。

**來源**：IB P.68 Adding a Negative Number 的 Pattern 推導方法移植 + 課本 P.17 絕對值引入

**互動設計**：

```
畫面呈現一個靜態數線（-6 到 +6）
下方逐行出現點的位置與距離：

點的位置    到原點的距離
  -4     →     4
  -3     →     3
  -2     →     2
  -1     →     1
   0     →     0
  +1     →     1
  +2     →     2
  +3     →   [學生填入]
  +4     →   [學生填入]
  -3.5   →   [學生填入]

引導問題：
Q1：「正數的距離，等於這個數本身嗎？」（是/否）
Q2：「負數的距離，等於什麼？」（學生填空）
Q3：「+3 和 -3 的距離一樣嗎？為什麼？」（文字輸入）

完成後顯示：
「數學上，我們把一個數到原點的距離叫做『絕對值』，
寫成 |a|。絕對值永遠 ≥ 0，因為距離不可能是負的。」
```

**解鎖條件**：Q1–Q3 全部回答後解鎖 Phase 1

### Phase 1｜主 Canvas：靜態絕對值互動數線

**教學目標**：視覺化「點 A 到原點的距離」，強化距離 ≠ 去負號的直覺。

**來源**：課本 P.17–19（例4–6）+ PhET Number Line: Integers 的設計概念

**Canvas 規格**：

```
尺寸：寬度 100%，高度 220px

元素：
  - 水平數線：-10 到 +10
  - 原點 O：固定藍色圓點
  - 點 A：紅色可拖曳圓點（顯示座標標籤）
  - 距離線段：橘色粗線，從點 A 到原點 O
  - 線段上顯示距離數值（隨拖曳即時更新）

右側即時資料面板：
  A 的座標 = ___
  |A| = ___（橘色字）
  |A| ≥ 0 的說明（當 A 在負半軸時特別強調）

關鍵設計細節：
  當點 A 是負數時，橘色距離線段從 A 畫到原點
  而不是只顯示數字——這是打破「去負號」迷思的視覺核心
  
  額外提示（A 在負半軸時）：
  「雖然座標是負的，但距離永遠是正的！」（底部提示卡）
```

**情境切換按鈕**（右上角）：

```
🌡️ 溫度計模式
  數線垂直顯示，0°C 為原點
  拖曳溫度點，顯示「距離 0°C 幾度」

⛏️ 礦坑模式（垂直數線）
  頂端：鑽探平台 +20m
  地面：0m
  地下工作區：-8m
  側井：-12m
  礦場：-28m
  各位置固定顯示，學生拖曳「電梯」到指定位置
  顯示「電梯距地面 ___ 公尺」
```

**歸納問題**（拖曳操作後顯示）：

```
Q1：「|3| 和 |-3| 哪個比較大？」
    → 讓學生驗證，發現兩者相等
Q2：「有沒有一個數，它的絕對值是 -2？」
    → 這是「Thinking」題（課本 P.17），引導迷思挑戰
    → 暫時不解答，作為 Phase 4 的引子
```

### Phase 2｜相反數與絕對值的關係

**教學目標**：讓學生理解 `|a| = |-a|`，連結相反數與絕對值的關係。

**來源**：課本 P.16–17（相反數 + 絕對值定義）

**互動設計**：

```
畫面：數線上同時顯示 +a 和 -a 兩個點
  兩個點用不同顏色標示（藍 / 紅）
  兩條距離線段同時顯示（從兩點各延伸到原點）

學生操作：
  拖動滑桿改變 a 的值（1 到 10）
  觀察兩條距離線段始終等長

右側顯示：
  |a| = ___
  |-a| = ___
  兩者是否相等？（即時更新）

引導問題：
Q1：「不管 a 是什麼正數，|a| 和 |-a| 的關係是？」
Q2：「這和相反數的定義有什麼關聯？」
    （相反數定義：到原點距離相等，在原點兩側）

完成後顯示結論卡片：
  「互為相反數的兩個數，絕對值相等：|a| = |-a|」
  對應課本 P.20 重點回顧第4點
```

### Phase 3｜雙點距離 `AB = |a-b|`

**教學目標**：從單點距離推廣到兩點距離，建立 `|a-b|` 的幾何意義。

**來源**：課本 P.40–42（數線上兩點間的距離）+ IB P.67 Example 5

#### Sub-Phase 3A｜靜態雙點距離

```
Canvas 新增：點 B（綠色可拖曳圓點）

顯示三段距離：
  |A|（紅色線段，A 到原點）
  |B|（綠色線段，B 到原點）
  AB（紫色線段，A 到 B）

右側即時顯示：
  A 的座標 = ___
  B 的座標 = ___
  AB = |a-b| = |___ - ___| = ___

關鍵互動：
  按鈕「交換 A、B 位置」
  觀察 AB 距離不變（|a-b| = |b-a|）
  這對應課本 P.40 探索活動的核心發現

引導問題：
Q1：「把 A 和 B 對調，AB 的距離改變了嗎？」
Q2：「為什麼 |a-b| = |b-a|？」（提示：想想相反數）
```

#### Sub-Phase 3B｜礦坑距離計算

```
切換到礦坑垂直數線模式
固定位置：鑽探平台（+20）、地面（0）、地下工作區（-8）、礦場（-28）

題目序列（對應 IB P.78 Q12 礦坑題）：
  題1：「從地面到礦場的距離是幾公尺？」
       計算：|0 - (-28)| = 28
  題2：「地下工作區和側井的距離？」
       計算：|(-8) - (-12)| = 4
  題3：「哪兩個位置距離最遠？」
       學生選擇，系統計算驗證

學生在垂直數線上點選兩個位置
系統自動計算並顯示算式和距離線段
```

### Phase 4｜動態追逐（青蛙追蟲）

**教學目標**：讓 `|a-b|` 從靜態公式變成「能預測結果的動態工具」。

**來源**：IB P.80 Review Set 3B Q12「Fergus the Frog」

**互動規格**：

```
初始設定（可調整）：
  青蛙（點 A）：預設在 -6
  蟲（點 B）：預設在 +4
  初始距離 = |(-6) - 4| = 10

每回合操作：
  按「跳一次」按鈕
  青蛙移動：+3（預設，可調整）
  蟲移動：+1（預設，可調整）
  數線兩點即時更新
  右側顯示：距離 = |A - B| = ___（即時計算）

追逐記錄表（右側）：
  回合 | 青蛙位置 | 蟲位置 | 距離
    0  |   -6    |   +4   |  10
    1  |   -3    |   +5   |   8
    2  |    0    |   +6   |   6
  ... （持續更新）

引導問題序列：
Q1：「按幾次之後青蛙追到蟲？」（學生先猜，再操作驗證）
Q2：「每次距離縮短幾格？」（觀察規律：10→8→6→4→2→0，每次縮短2）
Q3：「為什麼每次縮短 2？和青蛙的步長、蟲的步長有什麼關係？」
    （提示：3 - 1 = 2，這就是距離縮短量）
Q4：「如果青蛙每次跳 4 格，蟲逃 1 格，需要幾次？」
    （學生修改參數，重新觀察）

可調整參數：
  青蛙步長：1 到 6
  蟲步長：0 到 3
  初始距離：5 到 20

最終連結：
  「距離縮短量 = 青蛙步長 - 蟲步長」
  「預測追到時間 = 初始距離 ÷ 縮短量」
  對應課本 P.41 例11（數線上兩點距離）和例12（與定點等距離的坐標）
```

### Phase 5｜迷思挑戰（打破「絕對值可以是負數」）

**教學目標**：讓學生透過反例自己推翻「絕對值等於負數」的錯誤直覺。

**來源**：課本 P.17 Thinking「有沒有絕對值等於 -2.7 的數？」

**互動設計**：

```
挑戰一：「絕對值等於負數？」
  問題：「哪個數的絕對值等於 -5？」
  學生在數線上嘗試放置一個點
  無論放哪裡，系統顯示：「這個點到原點的距離是 ___，不是 -5」
  無論正負，距離都 ≥ 0
  結論：「找不到！因為距離不可能是負的，所以絕對值不可能是負數。」

挑戰二：「知道絕對值，能找到原來的數嗎？」
  問題：「如果 |甲數| = 5，甲數是多少？」（課本 P.18 例4）
  互動：學生在數線上點選，找出滿足條件的點
  系統提示：「有幾個？都找到了嗎？」
  答案：+5 和 -5 都滿足
  延伸：「|甲數| = 0 呢？」→ 只有 0

挑戰三：「絕對值小於某數的整數」（課本 P.18 例5）
  問題：「絕對值小於 6 的整數有哪些？」
  學生在數線上點選所有滿足條件的整數點
  系統自動驗證（|點的座標| < 6 才能選）
  選完後顯示計數：「你找到 ___ 個整數」
```

## 五、設計決策備忘

| 決策點 | 選擇 | 理由 |
|--------|------|------|
| 情境選擇 | 礦坑（垂直）+ 走路（水平）並存 | 讓學生理解數線方向不影響距離的本質 |
| 青蛙追蟲的位置 | Phase 4 核心互動（不是附加關卡） | 唯一讓 `\|a-b\|` 有預測功能的動態活動 |
| 迷思挑戰的位置 | 最後（Phase 5） | 必須先理解距離，才能理解「負距離不存在」 |
| Pattern 推導的位置 | 最前（Phase 0） | 學生需要先「發現」定義，再接觸符號 |
| 雙點距離的設計 | 三色線段並存（\|A\|, \|B\|, AB） | 讓學生看清楚單點距離和兩點距離的關係 |
