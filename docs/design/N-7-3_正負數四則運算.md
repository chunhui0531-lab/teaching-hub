## 一、學習目標

| 層次 | 目標描述 |
|------|----------|
| 認知 | 理解正負數加減的符號規律（同號/異號）；理解乘除的正負規則 |

| 推理 | 理解「減去負數等於加正數」的結構原因，而非死背規則 |

### Phase 0｜行動序列器（動作 → 算式）

**教學目標**：補上課本跳過的橋樑——讓學生主動把語言動作翻譯成數學算式，而非被動接受算式。

**來源**：IB P.65 Exercise 3A Q6「State the combined effect of...」的互動化版本

**互動設計**：

```
畫面上方：情境描述卡片（可切換）
  情境A：「存入 $70，隨後領出 $100」
  情境B：「電梯上樓 8 層，再下樓 9 層」
  情境C：「氣溫上升 5°C，隨後下降 12°C」
  情境D：「向東走 4 公里，再向西走 7 公里」

畫面下方：積木拖曳區
  積木庫：[↑正向] [↓負向] + 數字輸入
  序列槽：學生把積木拖入，組成動作序列

系統輸出（學生填完後）：
  「你的動作序列 = ___」（自動生成算式）
  「結果是正的還是負的？先猜，再看答案。」
```

**對應課本**：P.65 Exercise 3A Q6（a-f 六小題全部可作為情境來源）

**解鎖條件**：完成 2 個情境後解鎖 Phase 1

### Phase 1｜數線行走動畫（Canvas A）

**教學目標**：視覺化正負數加法的「方向+距離」結構，建立同號/異號加法的直覺。

**來源**：課本 P.23–28（例1–4）+ IB P.67 Example 5

**Canvas A 規格**：

```
元素：
  - 數線範圍：-15 到 +15
  - 起點滑桿：可設定 -10 到 +10
  - 第一步箭頭：可拖曳（設定方向和長度，-10 到 +10）
  - 第二步箭頭：可拖曳
  - 自動顯示算式：起點 + 第一步 + 第二步 = ?
  - 學生填入答案，系統驗證

情境切換按鈕（右上角）：
  🌡️ 溫度計模式（對應課本 P.30）
     → 數線垂直顯示，起點 = 今天氣溫，箭頭 = 溫差
  🚶 走路模式（對應課本 P.23）
     → 水平數線，向東/向西
  🏢 電梯模式（對應 IB P.67）
     → 垂直數線，樓層標示
```

**歸納引導問題**（答題後才能繼續）：

```
Q1：「兩個正數相加，結果的符號是？」
Q2：「兩個負數相加，結果的符號是？」
Q3：「一正一負相加，結果的符號由誰決定？」
→ 填完後系統顯示「同號數相加」和「異號數相加」的規律卡片
（對應課本 P.24–28 的重點回顧格式）
```

### Phase 2｜正負相消（Canvas B）

**教學目標**：建立「正負抵銷」的視覺直覺，連結到「相反數的和為 0」的抽象定義。

**來源**：課本 P.25「兩相反數的和」+ Mathigon 代數積木概念 + IB P.78 高爾夫記分板

**Canvas B 規格（雙版本可切換）**：

**版本一：抽象積木版**

```
正積木（綠色方塊）：代表 +1
負積木（紅色方塊）：代表 -1
操作：從積木庫拖入框中
動畫：正負配對時自動靠攏 → 變灰 → 消除
剩餘積木：顯示最終結果
引導問題：「你放了幾個正積木、幾個負積木？消完後剩幾個？」
```

**版本二：高爾夫記分板版（情境版）**

```
畫面：9洞記分板
每洞顯示：
  - Par 值（基準桿）：3 或 4 或 5（學生可調整）
  - 實際桿數輸入框
  - 系統計算：自動顯示 +□ 或 -□
底部計算：正分和負分加總
關鍵動畫：當某洞 +3 和另一洞 -3 剛好抵銷時，兩格同時變灰色
核心問題：「Par 5 的洞你打了 3 桿，這個洞的分數是？為什麼？」

教學亮點（課本沒有的）：
每個洞的 Par 值不同 → 讓學生理解「零點是相對的，不是固定的」
對應課本 P.21 Review Q1（高爾夫 Triple Bogey / Eagle）的互動化版本
```

**Phase 2 解鎖條件**：積木版完成 3 題 + 記分板完成 1 輪

### Phase 3｜乘除符號方向感（鯊魚與安全島遊戲）

**教學目標**：讓學生透過遊戲直覺建立「負負得正」的方向感，而非死背規則。

**來源**：IB P.68–70 Activity 1–2「Sharks vs Safety」

**遊戲規格**：

```
場景：數線從 -8 到 +8
  左端：鯊魚（危險）
  右端：安全島（目標）
  起點：0

兩個虛擬轉盤（點擊旋轉）：
  轉盤一：方向
    + 正向（面朝安全島）
    - 負向（面朝鯊魚）
  轉盤二：步數
    +1 到 +6（一般步數）

組合結果與角色動畫：
  (+方向) × (+步數) → 往右走（靠近安全島）✅
  (-方向) × (+步數) → 往左走（靠近鯊魚）⚠️
  (+方向) × (-步數) → 往左走（面朝安全島但退步）⚠️
  (-方向) × (-步數) → 往右走（面朝鯊魚但退步，反而遠離鯊魚）✅

引導問題（每種組合出現後）：
  「你面朝安全島方向，但步數是負的，結果往哪邊走？」
  「你面朝鯊魚，步數也是負的，結果往哪邊走？這合理嗎？」

歸納卡片（對應課本 P.47）：
  同號相乘 → 正數（往安全島方向）
  異號相乘 → 負數（往鯊魚方向）
```

**挑戰模式**：學生需在 10 步內讓角色到達安全島並停留，系統計分。

### Phase 4｜去括號（逐項翻轉 + 雙層括號挑戰）

**教學目標**：讓學生理解去括號「每項符號都翻轉」的結構原因，而非只背規則。

**來源**：課本 P.37–39（例9、探索活動、例10）

#### Sub-Phase 4A｜Pattern 推導前置（IB 方法）

```
顯示數列（對應 IB P.69 的 Pattern 建立方式）：
  5 - (3 + 2) = 5 - 5 = 0
  5 - (3 + 1) = 5 - 4 = 1
  5 - (3 + 0) = 5 - 3 = 2
  5 - (3 + -1) = ?    ← 學生填入
  5 - (3 - 1) = ?     ← 學生填入

問題：「你發現括號內的數變小時，整體結果怎麼變？」
→ 引導學生看出「減去一個數等於加它的相反數」的 Pattern
→ 對應課本 P.31 的「正負數的減法」核心概念
```

#### Sub-Phase 4B｜逐項翻轉動畫

```
六道預設算式（難度序列）：
  1. -(+3+2)           → 兩個正項，全部變負
  2. -(5-2)            → 正號省略的情況
  3. -(+4-1+6)         → 三項混合
  4. -(-3+2)           → 第一項就是負的（最易出錯）
  5. -(+5-3-2)         → 連續兩個負項
  6. -(-4-(-2)+3)      → 含相反數的相反數

動畫流程（每道題）：
  階段A：顯示原始算式，括號前的「-」橘色脈衝
  階段B：光標從「-」出發向右掃描
        每掃到一個性質符號，符號閃紅 → 翻轉
        每翻轉一個，計數器 +1
  階段C：括號消失，結果穩定顯示，綠色底框

觀察問題（動畫後顯示，需回答才能繼續）：
  Q1：「括號前的負號讓每一項符號發生了什麼變化？」
      ○ 全部變正  ○ 全部變負  ○ 每項都翻轉  ○ 沒有變化
  Q2：「如果括號前是『+』號，符號會翻轉嗎？」
      （學生選完後播放 +(+5-3+2) 的對照動畫）
```

#### Sub-Phase 4C｜雙層括號挑戰

```
六道題目（難度遞增）：
  題1：5 - (3 + 2)                    → 最基本
  題2：10 - (7 - 3)                   → 減後跟減，最常出錯
  題3：20 - (5 + (8 - 3))             → 雙層，內層全正
  題4：30 - (10 - (6 + 2))            → 雙層，外層負+內層負（雙重翻轉）
  題5：(15 + 3) - (8 - (4 - 1))       → 左側也有括號
  題6：自訂題（學生輸入）

路徑選擇設計：
  每題讓學生選「先拆外層」或「先拆內層」
  兩條路都能走，結果相同，但過程不同
  完成後系統比較兩條路的差異，顯示「結論卡片」

三次提示機制：
  第1次錯：「符號不對，回頭看看 Phase 4A 的翻轉規則」
  第2次錯：高亮問題符號，「這個符號被負號掃到，應該變成什麼？」
  第3次錯：直接顯示正確符號，但學生還是要自己輸入數字

步驟標籤設計（對應 IB P.75 Example 9 的格式）：
  每個填空框旁顯示灰色 step-label
  填對後 label 變綠並鎖定
  例：「{先拆外層括號}」「{符號翻轉}」「{化簡}」
```

### Phase 5｜負數魔方陣（鞏固挑戰關卡）

**教學目標**：在趣味情境中大量練習正負數加減，鞏固計算熟練度。

**來源**：IB P.71 Activity 3「Magic Squares」

**關卡設計**：

```
Level 1：3×3 魔方陣
  目標和 = 0
  數字範圍：-3 到 +3
  提示：散落的數字磚塊（拖曳放入格子）
  回饋：某行/列達標時該行/列發光

Level 2：3×3 魔方陣
  目標和 = -3（或學生自選）
  數字含小數（如 -1.5、+2.5）

Level 3：4×4 魔方陣
  目標和由學生自訂
  數字由系統隨機生成

視覺回饋設計：
  行/列達標：發光動畫 + 「✓ 這行總和 = 目標」
  全部達標：爆炸特效 + 解鎖下一 Level
  數字填錯：格子微震動，不直接說哪裡錯
```

## 五、設計決策備忘

| 決策點 | 選擇 | 理由 |
|--------|------|------|
| 鯊魚遊戲的位置 | 乘法 Phase（Phase 3），不是去括號主線 | 鯊魚遊戲教的是乘法負負得正，不是加減去括號 |
| 去括號的入口 | Pattern 推導前置（4A），而非直接上動畫 | IB P.69 的數列方法讓「減去負數」有推導感，不是規則記憶 |
| 高爾夫記分板的位置 | Canvas B 的情境版本（非獨立 Phase） | 它補充積木相消的語意，兩者並列而非取代 |
| 魔方陣的位置 | 最後鞏固關卡（Phase 5） | 練習工具，不是概念建立工具，必須在理解後才有意義 |
| 提示機制 | 三層遞進，不直接給答案 | 保留學生自我修正的空間，避免「看答案抄」的學習模式 |
