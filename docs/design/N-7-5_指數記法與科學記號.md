## 一、學習目標

| 層次 | 目標描述 |
|------|----------|
| 認知 | 理解指數記法的意義（連乘的簡記）；理解科學記號的格式規定（1 ≤ a < 10，m 為整數） |
| 操作 | 能把任意整數或小數轉換為科學記號；能把科學記號展開為一般形式 |
| 推理 | 理解 `×10 = 次方+1` 的規律；能用科學記號比較兩個極大或極小的數 |

---

## 二、核心設計原則

**先建立「為什麼需要」，再教「怎麼做」**

課本從金幣故事出發，但沒有充分建立「科學記號解決了什麼問題」的動機感。本網頁在進入技術操作之前，先讓學生體驗「一般寫法有多麻煩」，再呈現科學記號的優雅。

```
設計路徑：
規模感知（為什麼需要指數記法）
    ↓
指數感知（底數固定，感受次方增長）
    ↓
體感校準（指數增長超出直覺的衝擊）
    ↓
位值橋樑（10 的次方 = 位值，建立負指數直覺）
    ↓
科學記號拆解器（a × 10ⁿ 的轉換）
    ↓
規模排列挑戰（用科學記號比較大小的實際應用）
```

## 三、完整分頁架構

### Phase 0｜規模感知器（動機建立）

**教學目標**：讓學生親身感受「一般寫法數零很痛苦」，建立學習科學記號的動機。

**來源**：IB P.62 開場問題精神 + 課本 P.69 巨型病毒情境

**互動設計**：

```
畫面設計：左右並排兩個場景卡片

左卡片（極小）：
  「潘朵拉病毒的直徑」
  顯示：0.000001 公尺
  問題：「這個數有幾個零？請數數看。」
  下方輸入框：學生填入「___ 個零」
  （答案：6 個，很容易數錯）

右卡片（極大）：
  「地球到太陽的距離」
  顯示：149600000000 公尺
  問題：「這個數有幾位數？請數數看。」
  下方輸入框：學生填入「___ 位數」
  （答案：12 位，幾乎無法一眼看清楚）

兩題都填完後：

畫面動畫切換：

左卡片：「1 × 10⁻⁶ 公尺」
右卡片：「1.496 × 10¹¹ 公尺」

提示文字（出現動畫）：
「科學記號讓你 3 秒內就能知道：
 病毒的直徑是小數點後第 6 位才有數字，
 地球到太陽的距離是 12 位數。
 現在來學怎麼用它。」

對照問題：
Q：「用科學記號後，哪個數比較大？你怎麼知道？」
   （學生輸入，引導到「次方越大，數越大」的直覺）
```

### Phase 1｜指數感知（關卡一）

**教學目標**：建立「同一個數連乘 n 次 = aⁿ」的基本概念，感受指數增長的速度。

**來源**：課本 P.63–67（例1–2）+ 課本 P.67 探索活動

#### Sub-Phase 1A｜格子圖（指數記法定義）

```
底數選擇按鈕：2 / 3 / 10（預設從 2 開始）
指數滑桿：1 到 10

左側：展開式
  2 × 2 × 2 = ...（隨指數自動更新，多餘的 × 被灰色顯示）

中間：指數記法
  大字顯示 2ⁿ 和對應的數值

右側：格子視覺圖（方格填色）
  2¹ = 2  → 2 個格子
  2² = 4  → 4 個格子
  2³ = 8  → 8 個格子
  2⁴ = 16 → 16 個格子
  ...（格子太多時縮小單格，保持在可視範圍內）

關鍵說明標籤（底部）：
  「2 稱為底數，n 稱為指數」
  隨滑桿更新：「底數 = ___，指數 = ___」

歸納問題（滑桿拖過 1–5 後解鎖）：
Q1：「aⁿ 代表什麼意思？」（選擇題）
   A. a 加上 n 次   B. a 乘以 n 次   C. a 乘以自己 n 次   D. n × a
Q2：「底數和指數，哪個對最終結果的影響更大？」（文字輸入）
```

#### Sub-Phase 1B｜體感校準（指數增長的衝擊）

```
畫面：三個問題逐一出現（前一個答完才出現下一個）

問題 1：
  「2 的 10 次方，大概是多少？先猜猜看。」
  學生輸入猜測值
  按「揭曉」→ 顯示 1,024
  「你猜的是 ___，實際是 1,024」（如果猜對了，特別稱讚）

問題 2：
  「2 的 20 次方呢？」
  學生輸入猜測值
  按「揭曉」→ 顯示 1,048,576（超過 100 萬）
  「100 萬！你想到了嗎？」

問題 3：
  「2 的 30 次方呢？」
  學生輸入猜測值
  按「揭曉」→ 顯示 1,073,741,824（超過 10 億）
  「超過 10 億！從 1 次方到 30 次方，數字增長的速度遠超我們的直覺。」

結語動畫：
  「這就是為什麼科學家需要一種簡潔的寫法——
   10³⁰ 比 1073741824 清楚多了。」

對應課本 P.67 探索活動「比較大小」和補給站「1.01 法則」的互動化版本
```

### Phase 2｜位值橋樑（10 的次方 = 位值對照表）

**教學目標**：建立「×10 = 次方+1」的直覺，同時理解負指數的意義。

**來源**：課本 P.68 位值對照表（本網頁最核心的橋樑概念）

**互動設計**：

```
主體：水平滑動軌道
  軌道上的位置從左到右：10⁻³, 10⁻², 10⁻¹, 10⁰, 10¹, 10², 10³, ..., 10⁹

滑桿：學生拖動，指向某個位置

每個位置同步顯示三行資訊：
  行1（位名）：千分位 / 百分位 / 十分位 / 個位 / 十位 / 百位 / 千位 ...
  行2（位值）：0.001 / 0.01 / 0.1 / 1 / 10 / 100 / 1000 ...
  行3（次方）：10⁻³ / 10⁻² / 10⁻¹ / 10⁰ / 10¹ / 10² / 10³ ...

動畫效果（拖動時）：
  滑動一格，次方數字用動畫遞增/遞減 +1/-1
  位值的小數點動畫左移/右移一格

關鍵觀察問題（拖動 3 格以上後解鎖）：
Q1：「向右滑一格，位值變為原來的幾倍？次方變化是？」
   → 引導學生說出「×10，次方+1」
Q2：「向左滑一格，位值變為原來的幾倍？次方變化是？」
   → 引導學生說出「×0.1，次方-1」
Q3：「1 等於 10 的幾次方？0.1 呢？0.001 呢？」
   → 讓學生自己填入（對應課本 P.68 的 10⁰, 10⁻¹, 10⁻³）

完成後顯示記憶卡：
  「×10 → 次方 +1」
  「÷10 → 次方 -1」
  「1 = 10⁰，0.1 = 10⁻¹，0.01 = 10⁻²」
```

### Phase 3｜科學記號拆解器（關卡二）

**教學目標**：掌握整數/小數與科學記號的雙向轉換，理解 `1 ≤ a < 10` 的限制原因。

**來源**：課本 P.69–71（例3、例4）

#### Sub-Phase 3A｜一般數 → 科學記號

```
輸入框：學生輸入任意整數或小數

動畫流程（輸入後按「拆解」）：
  步驟1：數字展示在畫面中央
  步驟2：小數點動畫移動（光點掃過）
          移動一格 = 次方 ±1
          系統計數移動格數（右上角計數器）
  步驟3：小數點停在「符合 1 ≤ a < 10」的位置
  步驟4：顯示結果框：a × 10ⁿ
          a 用一個顏色，10ⁿ 用另一個顏色

下方填空（學生自己填入）：
  「這個數 = ___ × 10^___」
  「a = ___（1 ≤ a < 10）」
  「n = ___（整數，移動了幾格）」

六道預設練習題（對應課本 P.70 例3）：
  1. 120,000           → 1.2 × 10⁵
  2. 0.00000037        → 3.7 × 10⁻⁷
  3. 3/100,000         → 3 × 10⁻⁵
  4. 30,000,000        → 3 × 10⁷
  5. 0.000002          → 2 × 10⁻⁶
  6. 7/1,000,000       → 7 × 10⁻⁶

錯誤判斷設計：
  如果學生輸入 72.4 × 10¹⁸，系統說：
  「a = 72.4，不符合 1 ≤ a < 10，請再調整。」
  如果學生輸入 0.47 × 10¹⁵，系統說：
  「a = 0.47，比 1 還小，請再調整。」
  （對應課本 P.69 的錯誤範例說明）
```

#### Sub-Phase 3B｜科學記號 → 一般數（反向）

```
畫面顯示一個科學記號，學生展開成一般形式

動畫流程（按「展開」）：
  步驟1：顯示 a × 10ⁿ
  步驟2：10ⁿ 動畫展開成 n 個 10 連乘（n 較小時）
          或直接說明「小數點向右移 n 格」
  步驟3：數字填入展開後的格式

四道練習題（對應課本 P.71 例4）：
  1. 3.14 × 10⁷  → 31,400,000（8位數）
  2. 5.3 × 10⁻⁶  → 0.0000053（小數點後第6位）
  3. 7.68 × 10⁴  → 76,800（5位數）
  4. 2.345 × 10⁻⁹ → 0.000000002345（小數點後第9位）

學生填空兩個問題：
  「這個數是幾位數？___」（正指數題）
  「這個數從小數點後第幾位開始有非零數字？___」（負指數題）
  （對應課本 P.71 的規律總結）
```

### Phase 4｜規模排列挑戰（比較大小的應用）

**教學目標**：在有意義的情境中練習科學記號的比較大小，理解「次方先比，a 後比」的策略。

**來源**：課本 P.72 例5（科學記號比較大小）+ 方向二「規模感」的設計精神

**互動設計**：

```
挑戰設定：
  提供 7–8 個科學記號（混合正負次方），每個都有情境標籤
  學生把它們從最小到最大排列（拖曳排序）

情境組合（可切換不同主題組）：

主題組A「生物尺寸」：
  5 × 10⁻¹⁰ m（原子直徑）
  3 × 10⁻⁷ m（細菌大小）
  1 × 10⁻⁶ m（病毒直徑）
  1 × 10⁻³ m（塵蟎）
  2 × 10⁻² m（螞蟻）
  1.8 × 10⁰ m（人的身高）

主題組B「天文距離」：
  3.8 × 10⁸ m（地球到月球）
  1.5 × 10¹¹ m（地球到太陽）
  4.0 × 10¹³ m（太陽到最近恆星）
  9.5 × 10²⁰ m（銀河系直徑）

操作流程：
  學生拖曳卡片，調整順序
  按「檢查」後：
    正確位置的卡片保持不動（綠色邊框）
    錯誤位置的卡片標示（橘色邊框），提示「這張應該在___位置」

完成後：
  顯示對數比例尺（水平軸），各數在比例尺上的位置
  讓學生看到「這些數在宇宙尺度上的相對位置」
  特別標示幾個熟悉的參考點（人的身高、地球直徑等）

比較策略提示（第一次答錯後顯示）：
  「比較兩個科學記號，先比較次方（m 和 n）：
   - 次方大的那個數比較大
   - 次方相同時，再比較 a 的大小」
  對應課本 P.72 的比較策略說明
```

## 五、設計決策備忘

| 決策點 | 選擇 | 理由 |
|--------|------|------|
| 規模感知的位置 | 最前（Phase 0，動機建立） | 必須先讓學生感受「一般寫法的痛點」，才有學科學記號的動機 |
| 體感校準的設計 | 三題遞進（10次方 → 20 → 30） | 讓學生的「意外感」逐步加深，不是一次衝擊就過去 |
| 位值對照表的呈現 | 可拖動軌道（不是靜態表格） | 動態拖動讓「×10 = 次方+1」的規律有身體感，靜態表格沒有這個效果 |
| 科學記號的格式限制 | 提供即時錯誤回饋（不是事後評分） | 讓學生在嘗試過程中理解為什麼 `1 ≤ a < 10`，不是死記規定 |
| 規模排列的情境 | 分主題組（生物尺寸 / 天文距離） | 讓學生在自己熟悉的情境中比較，而不是純粹的數字比大小 |
| 對數比例尺的位置 | 排列完成後才顯示（不是一開始就給） | 比例尺應該是「驗證和延伸」，而不是輔助排列的工具 |
