# 00｜三版本教科書整合電子書 — 設計方法論模板

> **用途**：可複用的「內容分析方法 + 網頁架構規格」模板。套用方式是先填寫各章節留白處，再依此產出對應主題的正式設計文件（格式延續 N-7-3 / N-7-4 / N-7-5 三份既有文件）。
> **適用範圍**：任何國中數學單元的跨版本教科書整合設計，不綁定特定知識點。

---

## 〇、本文件在整體專案中的位置

- 本模板是「方法論層」，N-7-3 / N-7-4 / N-7-5（以及未來的新主題）設計文件是「個案產出層」。
- 套用本模板於新主題時，產出物應為一份新的『XXX_設計文件.md』，格式延續 N-7-3 範例：
  學習目標 → 核心設計原則 → 完整分頁架構 → Claude Code Prompt → 設計決策備忘 → 課本例題索引。
  但動筆前，先完整跑過本模板的 Stage 1 與 Stage 2，避免一開始就跳進互動細節。
- 圓心角與圓周角教案（曾椿惠老師）可作為「教案層級」的對照案例：其「迷思檢測→操作測量→視覺化對比→歸納說明→幾何推理」五階段，正是本模板「找元素→找關係→建系統」框架的一個具體實作版本，套用新主題時可回頭參照其節奏與提示機制設計。

---

## Stage 1｜內容分析方法論

這一步決定整個專案的「腦」，網頁只是「身體」。先做完這一步，才有資格談互動設計。

### 1.1 三版本對照矩陣（填空模板）

| 比較維度 | 版本A（____） | 版本B（____） | 版本C（____） | 差異／迷失訊號 |
|---|---|---|---|---|
| 切入情境／例題 | | | | |
| 呈現順序 | | | | |
| 處理迷思的方式 | | | | |
| 留白／刻意迴避的地方 | | | | |
| 練習題型結構 | | | | |

**填寫原則**：
- 逐項填入三版本的具體頁碼與例題描述，保留可追溯索引（比照既有文件的「對應課本 P.xx」格式）。
- 「差異／迷失訊號」欄不填表面差異，填「這個差異為什麼存在」的判斷——這才是後續設計的素材。

### 1.2 迷失節點標記準則

一個概念跳躍很可能是「迷失節點」，如果符合以下任一訊號：

1. **三版本都用同一招迴避**——例如都直接給規則，沒有任一版本正面解釋原因。
2. **篇幅落差**——某版本花特別多篇幅解釋，另外兩版本一筆帶過，代表編者對難度判斷不一致，落差本身就是訊號。
3. **正確率與課本內容不對等**——學生作答正確率低，但課本沒有對應的「常見錯誤類型」說明。
4. **量的混淆**——概念涉及「兩個不同性質的量被學生當作同一件事」（例如圓心角教案中「弧的度數」vs「弧長」、N-7-3 中「方向」vs「大小」）。

每標記一個節點，記錄三件事：節點描述 / 三版本各自的處理方式 / 你判斷的根本原因（不是表面症狀）。

### 1.3 教學路徑重組原則

- 預設順序：**具體操作 → 模式發現 → 抽象符號化**（「先有感效果，再有代數式」）。
- 重組後的順序不必對應任何單一版本，但每一步要能回答：「為什麼這一步放在這裡，前一步交給它什麼，它交給下一步什麼。」
- 若某步驟在三版本中都找不到對應，代表這是你補上的「橋樑步驟」（例如 N-7-3 的 Phase 0「行動序列器」就是補課本跳過的橋樑）——要特別標記並寫下設計理由。

## Stage 2｜網頁三層架構規格

每個主題網頁要同時滿足「分頁解鎖機制」與「整體不是片段拼貼」，作法是讓三層貫穿所有 Phase。

### 2.1 故事層（敘事主線）

- 全網頁只使用**一個**情境／角色／世界觀，貫穿所有 Phase，而不是每個 Phase 換一個不相關的情境。
- 每個 Phase 開頭用一句話交代「這個情境跟上一個 Phase 是同一條線的延伸」。
- 基準案例：圓心角教案的「圓心角是不變量」貫穿五階段。

### 2.2 概念層（結構地圖，常駐元件）

- 畫面固定角落顯示「概念地圖／進度軸」，呈現目前 Phase 在整體知識結構中的位置與**依賴關係**（不是單純完成度百分比）。
- 學生要能從進度軸看出「這個概念建立在哪個前置概念上」。
- UI 規格基準：小尺寸、不可關閉但可收合、進入新 Phase 時自動高亮對應節點。

### 2.3 互動層（找元素 → 找關係 → 建系統）

核心操作框架，對應認知三階段：

| 階段 | 教學意圖 | UI 模式類別 | 既有案例參考 |
|---|---|---|---|
| 找元素 | 讓學生先辨認情境中的關鍵物件／變量 | 拖曳標記、分類、命名 | N-7-3 Phase 0 行動序列器 |
| 找關係 | 觀察元素間如何互動，什麼變、什麼不變 | 可操作 Canvas、滑桿對比、固定變量觀察 | 圓心角教案「固定圓心角改半徑」對比實驗 |
| 建系統 | 把發現的關係組織成可預測、可應用的規則 | 歸納填空、規律卡片、路徑選擇挑戰 | N-7-3 Phase 4 去括號雙路徑挑戰 |

套用時，每個 Phase 要明確標出自己屬於哪個階段，避免「互動好玩但沒有對應認知功能」。

## Stage 3｜視覺化降噪設計準則

### 3.1 顏色語義表（一次決定，全站沿用）

| 角色 | 顏色 | 套用範圍 |
|---|---|---|
| 不變量 | ____ | 全站固定，不可在不同主題改變語意 |
| 變量 | ____ | 全站固定 |
| 正確／解鎖 | ____ | |
| 錯誤／待修正 | ____ | 避免使用責備感強烈的顏色 |

> 決定一次，所有主題沿用，不要每個網頁重新定義。

### 3.2 漸進揭露規則

- 每個畫面只顯示「當前任務」需要的控制元件；尚未解鎖的功能用視覺上明顯但不可互動的方式預告。
- 資料／數值卡只在學生完成對應操作後才出現，不預先攤開全部數據。

### 3.3 定位錨點規格

- 概念地圖（2.2）即是定位錨點，不需要額外設計。
- 每個 Phase 切換時要有明確轉場提示（不是瞬間跳轉），讓學生感知「我從哪裡來，要去哪裡」。

## Stage 4｜套用 SOP（新主題上手清單）

1. 完成 1.1 三版本對照矩陣。
2. 完成 1.2，標記至少 3–5 個迷失節點。
3. 完成 1.3，寫出重組後的教學路徑（文字流程圖，比照 N-7-3「核心設計原則」格式）。
4. 決定 2.1 故事層的情境角色，全程統一。
5. 套用 2.3 表格，把每個 Phase 分類到「找元素／找關係／建系統」。
6. 確認 3.1 顏色語義沿用既有定義，不重新發明。
7. 依 N-7-3 文件格式產出正式設計文件：學習目標 → 核心設計原則 → 完整分頁架構 → Claude Code Prompt → 設計決策備忘 → 課本例題索引。
